Trifold Engenharia (Maringá-PR construtora, founded 2019-12-18) repositioned in 2025 around a black + orange identity. The CRM and any marketing collateral must align with these tokens.

**Why:** The official logo asset is named `logo-Trifold-laranja.webp` and the home page CSS uses orange `#F27A5E` (Elementor variable `--e-global-color-ad2b38c`) as the sole accent over a near-black background. Typography is Space Grotesk 400/600 (self-hosted at `/wp-content/uploads/2026/04/SpaceGrotesk-{Regular|SemiBold}.eot`). This is locked-in brand identity, not arbitrary styling.

**How to apply:** When designing email marketing, internal dashboards, or any client-facing asset for the CRM project, default to:
- Background: `#000000` (primary) / `#FFFFFF` (inverse surfaces)
- Accent / CTA: `#F27A5E` (orange) — use as solid button bg with black text, OR as text color, OR as 18%-opacity highlight gradient behind a phrase
- Secondary support palette (from Yarden project): `#1C3924` (deep green), `#D4E6D9` (mint), `#FFBC7D` (peach)
- Text on dark: `#FFFFFF` headings, `#BEBEBE` body, `#B4B4B4` / `#F1F1F1` for eyebrows
- Type: Space Grotesk (use 600 for headlines/buttons, 400 for body). Avoid Roboto/Roboto Slab — those are Elementor defaults the site overrides.
- Buttons: pill-ish or square — site uses both `border-radius: 4px` (cards) and `border-radius: 20px` (some elements); primary CTA is solid orange bg / black text / 600 weight / 1.1em / `text-transform: uppercase`. Ghost variant: translucent white bg `#FFFFFF4F`, 1px white border, white text, 400 weight.
- Voice: institutional but warm; Portuguese formal "você"; values-driven (Christian-rooted, "Engenharia é nosso sobrenome", "Jeito Trifold de Ser"); vocabulary: *boutique, exclusivo, sofisticação, excelência, BIM, transparência, parceria, residencial de alto padrão*.
