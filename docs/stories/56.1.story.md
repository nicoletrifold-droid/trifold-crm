# Story 56-1 — Biblioteca de Mídia da Nicole

## Metadata
- **Status:** InProgress
- **Epic:** 56 — Nicole / IA Features
- **Branch:** main

## Context
Gestores precisam de um local centralizado para armazenar imagens e PDFs de empreendimentos (plantas, fachadas, tabelas de preço) que podem ser enviados durante conversas com leads — tanto manualmente pelo corretor quanto futuramente pela IA de forma proativa.

## Acceptance Criteria
- [x] AC1: Seção separada em `Config > Nicole > Mídia`
- [x] AC2: Upload de JPG, PNG, WebP e PDF (max 20MB por arquivo)
- [x] AC3: Arquivos organizados por empreendimento (tabela `properties`)
- [x] AC4: Quando novo empreendimento é cadastrado, aparece automaticamente na lista
- [x] AC5: Cada arquivo tem título, empreendimento (opcional), categoria, tipo, ativo/inativo
- [x] AC6: Bucket `nicole-media` privado no Supabase Storage com RLS
- [x] AC7: Card "Mídia" visível em `Config > Nicole` para admin, supervisor e gerente-comercial
- [x] AC8: Corretor pode enviar mídia da biblioteca durante conversa (via `/broker/leads/[id]`)
- [x] AC9: Envio respeita janela de 24h do WhatsApp (mesmo controle do send-message)

## Out of Scope
- IA oferecer proativamente arquivos (story futura)
- Dashboard admin direto no lead-detail-drawer (story futura)
